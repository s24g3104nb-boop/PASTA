# 13 完成料理の画像分類とカロリー計算（ユーザー追加要件 2026-10-28）

## 意図・確定した方針
- アプリ第1機能で**乾麺を撮影してgを推定**する（束または広げた状態、基準物なし）。
- ユーザー保有の実写真は **20g / 40g / 60g / 80g / 100g** の乾麺写真。**写真は本パッケージに未同梱**。撮影形態・各枚数・製品は不明。
- 料理機能は第2段階。ネット公開画像や適切な許諾のあるデータから、**料理の「名前／カテゴリー」を分類**する。例：カルボナーラ、ボロネーゼ、ミートソース。
- **完成料理について重量ごと（何g）の学習データは原則不要**とする。アプリが同一料理に使った乾麺重量を既に知っていることを前提にする。

## 大事な制約
乾麺gで計算できるのは、**乾麺部分の栄養**。料理の総kcalはソース・具・油・調味料で変動する。完成料理の写真から「カルボナーラ」と分類できても、卵・チーズ・ベーコン・油等の実際の量は通常分からない。

乾麺重量は、その料理の**同一調理バッチ**に属する時だけ再利用する。複数人に分けるなら食べた割合/人数が必要。別日に撮ったパスタ写真のgを自動で流用してはいけない。

## おすすめするMVP実装（将来段階・設計先行）
1. 乾麺の計測履歴を作成する。例：2026-xx-xx、乾麺100g、製品A、推定方式、実測有無。
2. 「この乾麺で料理を作る」を選ぶと `cooking_session` を作る。**乾麺計測記録IDに紐付ける**。
3. 完成料理の写真をアップロード。料理分類器が `カルボナーラ`, `ボロネーゼ`, `その他/不明` などの候補を返す。低信頼・未学習は「判別できません」とし、手動選択可能。
4. 選択された料理の**材料リストの雛形**（例：カルボナーラなら卵、チーズ、ベーコン、油）を表示。利用者が実際に使った材料と量を入力・修正する。
   - 省略する場合は、標準レシピ由来の**推定値**であることと出典・前提分量を表示。
5. `total_kcal = (dry_g / 100) * dry_kcal_per_100g + Σ(amount_ingredient_g / 100 * ingredient_kcal_per_100g)`。PFCも同様（必要な単位換算を実装）。水そのもののカロリーは0だが、油・ソースは計算に含める。
6. `per_serving_kcal = total_kcal * user_consumed_fraction`（または料理全体を等分する場合 `total_kcal / servings`）。完成料理写真だけでは何割食べたかは判断できない。
7. 結果画面に「乾麺分」「追加材料分」「料理合計」「1人前推定値」と前提条件を分けて表示。

## 画像分類データについて
- 学習対象は**料理の種類**であり「写真から重量/総カロリーを直接回帰」ではない。
- インターネット上の画像は無制限に学習利用・再配布できるとは限らない。利用許諾・データセット規約・出典・個人情報を確認し、許可されたデータを利用する。リポジトリに無断で第三者画像を同梱しない。
- 料理名の表記ゆれ（ミートソース、ボロネーゼ）、複数クラス、実写とレシピサイト写真の分布差に注意する。
- モデル未訓練でも先に料理名の手動選択・材料入力で栄養計算を完成できるようにする。
- 調理後の写真単体で精確な総kcal、個々の材料量を推定できるように見せない。

## DB/API/UI 草案
- `cooking_sessions(id, measured_dry_record_id, selected_dish, classifier_label, classifier_score, photo_path, servings, created_at)`
- `cooking_ingredients(id, session_id, ingredient_id, amount_g, kcal_per_100g, protein_per_100g, fat_per_100g, carbohydrate_per_100g)`
- `recipe_templates(dish_type, template_name, source, default_servings, ingredients_json)`
- 画面: 乾麺重量結果 → 「この乾麺で料理を作る」 → 完成料理撮影／種類選択 → 材料確認 → カロリー内訳と分量。
- **互換性**: 既存の計測履歴・食品マスタを壊さず、安全なDBマイグレーションを用意。

## 受入テスト例
- 乾麺100g（kcal/100g=350）・卵1個70kcal・ベーコン100kcal・チーズ80kcalなら、料理全体600kcal、2人に等分なら300kcal/人。※値は計算動作確認のテスト用で実製品栄養値ではない。
- 使用量を変えると計算結果が再現可能に変化する。
- カテゴリー未判定でも手動選択できる。
- 写真分類結果だけから材料分のkcalを「実測確定」と表示しない。
