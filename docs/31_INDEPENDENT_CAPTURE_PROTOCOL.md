# 方式B：独立試料の撮影と分割の確認手順

作成日：2026年11月10日。これは今後の実験計画であり、未収集の写真・未確認の系譜・未実施の評価を実績として扱わない。

## 現在のデータの扱い

新規15枚は名目20/40/60/80/100g、同重量の3枚は同じ試料の撮影グループ。重量間の麺の共有・積み増し・再配分は未確認なので、独立した5試料と仮定しない。既存58枚・旧15枚・50本34gの校正写真との共有関係も、証拠がない限り保守的に保持する。

現在の15枚とその縮小・回転・JPEG画像を、独立した学習/検証/テストへ自動分割しない。写真ファイルやハッシュが異なることは、物理試料が独立という証拠ではない。0.68g/本の校正を未確認の別製品へ転用しない。

これまでに方式の調整や選択に使った写真を、今後「一度も見ていない最終テスト」と呼ばない。現在の写真は、前処理・安定性・失敗条件の開発資料として引き続き利用できる。

## 最小のパイロット案

最初は同じ製品・同じ長さの乾麺に限定し、麺を共有しない25試料を作る。

| 名目重量 | 別々の試料数 | 試料ごとの配置 | 学習 | 検証 | 封印テスト |
|---|---:|---:|---:|---:|---:|
| 20g | 5 | 3配置 | 3試料 | 1試料 | 1試料 |
| 40g | 5 | 3配置 | 3試料 | 1試料 | 1試料 |
| 60g | 5 | 3配置 | 3試料 | 1試料 | 1試料 |
| 80g | 5 | 3配置 | 3試料 | 1試料 | 1試料 |
| 100g | 5 | 3配置 | 3試料 | 1試料 | 1試料 |

合計25試料・75枚。再使用しない場合、名目量の合計は約1.5kgになる。これは撮影計画の例であり、購入の指示や十分な標本数の保証ではない。材料が足りず再使用した場合は、親材料と再配分を記録して同系列として扱う。画像枚数だけを75枚にしても独立試料の不足は解消しない。

同じ試料の3配置は、例えば「重なりを少なく広げる」「自然に重ねる」「細くまとめる」とし、配置だけ変えて麺は足し引きしない。変更したら新しい秤量記録と親試料の関係を残す。麺の全長が画像内に収まる基準撮影を優先する。

各重量のどの試料をtrain/validation/testにするかは、モデルの結果を見る前に固定する。各試料の全配置、連写、再撮影、マスク修正版、縮小や再圧縮などの派生画像は同じ分割に置く。

この構成ではテストが各重量1試料しかなく、誤差や失敗率の不確実性が大きい。方式を絞る初期試験用であり、MAE5gを証明する十分な評価セットではない。最終評価には未見試料と別日の撮影を増やす。

## 撮影条件を重量から切り離す

重量が大きい写真だけ遠距離、特定の向き、特定の背景になると、背景や構図を重量の手掛かりとして覚える恐れがある。

- 全重量に同じ撮影距離の基準条件を用意し、距離を数値で記録する。近/中/遠を試す場合、全重量に同じ条件が入るようにする。
- 全重量に同じ背景・向き・照明条件を配置する。重量ラベルから撮影条件を決めない。条件の割当表と乱数を用いる場合のseedを撮影前に保存する。
- 台・トレー・寸法基準を使う場合はIDと実寸を別途測定する。「同じトレーに見える」ことだけで物理スケールの確認済みフラグを付けない。
- 同一製品での試験と、別銘柄/太さ/長さの試験は分けて記録する。同一製品での成功から未知製品への性能を主張しない。
- スマホ機種、カメラのズーム設定、撮影角度、撮影日を残す。デジタル縮小試験は、実際の距離・角度変更の代わりにはしない。

最初から全条件の組合せを撮る必要はない。まず上記の75枚を共通の基準条件で集め、独立試料数を確保する。その後、同じ試料に距離・照明等の対比較を追加する場合も、追加写真の分割は元試料の分割を継承する。

## 保存する台帳

| 区分 | 必要な項目 | 注意 |
|---|---|---|
| 原本 | image_id、original_id、original_sha256、原本パス、撮影日時 | 派生物は独自image_idを持ち、元のoriginal_id/原本SHAを維持 |
| 物理試料 | sample_id、physical_family_id、capture_group_id、parent_material_ids | 同じ麺・積み増し・再配分が分かる粒度で記録 |
| 確認根拠 | lineage_verified、lineage_confirmed_by、lineage_evidence | 人が確認した記録への参照。形式チェックだけでTrueにしない |
| 重量 | 実測表示値g、名目重量、秤の分解能g、秤ID、重量確認者/記録 | 名目20gと実測20.3gを混同しない。元の表示値を保存 |
| 製品 | 製品ID/名称、ロット、麺の太さmm、長さmm | 不明値は不明のまま。未確認値を代表値で埋めない |
| 撮影 | 距離、角度、機種、ズーム、背景ID、照明、配置、日付 | 同重量内だけでなく重量間でも条件をそろえる |
| 品質 | 原本検品、マスク版、マスク承認、欠け/反射/異物の確認 | 自動マスクは正解マスクとして自動承認しない |
| 分割 | train/validation/test、固定日時、分割台帳SHA-256 | 画像を見て都合よくテストを差し替えない |

製品の袋・ロットが同じであることと、実際の同じ麺を共有することは別。material IDは物理的な麺の共有可能性を表す。確認した上で最初から別容器へ分けた非共有の麺は、分離根拠を添えて別rootとして記録できる。未確認の再配分を別rootにすることは禁止する。袋やロットは製品メタデータに残し、同一ロットへの依存は評価上の制約として報告する。

## 系譜と分割の検査コード

追加モジュール：`pasta_weight_app_v2/experiments/lineage_protocol.py`

```python
from pasta_weight_app_v2.experiments.lineage_protocol import validate_split

# records、assignments、material_parentsは人が確認した非公開台帳から読む。
# 下記の関数自体が写真・CSV・DBを編集することはない。
summary = validate_split(records, assignments, material_parents)
```

recordsは上記のID・原本SHAと、`lineage_verified=True`、確認者、確認根拠、非空のparent_material_idsを持つ。assignmentsは全image_idに対する明示の分割で、余分なIDや未割当を許容しない。train/validation/testの3区分が必要。

material_parentsは「材料ID→親材料ID一覧」の明示グラフ。すべての参照先を記載し、確認済みの根だけを空の一覧 `[]` にする。未記載の親やunknownを独立した根として推定しない。循環したグラフも拒否する。

検査は以下を拒否する。

- 未確認・根拠なし・確認者なしの系譜、空欄やunknown/pendingのID。
- 画像IDの重複、同じoriginal_idに矛盾する原本SHA、分割の欠落/余分な割当/不正値。
- 同じ原本ID/SHA、試料、撮影群、物理系列が分割をまたぐこと。
- 異なる系列名を付け直しても、共通の親材料やその祖先を共有して分割をまたぐこと。
- 未記載の親材料、系譜の循環、暗黙の独立根。

戻り値の `split_manifest_sha256` は台帳全体・確認根拠・分割・材料グラフの指紋。重量ラベルが変わっても値が変わる。署名や人の承認ではなく、後から変更があったか照合するために使う。

`status=consistent_declared_split` は「申告した関係に矛盾する分割を検出しなかった」という意味に限る。コードは物理的な麺を追跡できず、根拠文書の真偽も確認しない。`independence_verified_by_code=False` を返す。重量ラベル/マスクの承認、学習の実行、モデルの本番採用は別工程。

## 封印テストと評価

1. 原本・実測ラベル・系譜・splitを人が確認し、SHA-256付き台帳と元データを非公開で保存する。
2. testを封印し、マスク閾値、特徴選択、Ridgeの正則化等はtrain/validationのみで検討する。
3. 採用候補、対応製品/重量範囲、拒否条件、合否基準を固定してからtestを一度評価する。
4. MAE/RMSE/最大絶対誤差、重量別・撮影状態別誤差、出力率・拒否率を集計する。派生写真数を独立試料数として扱わない。試料/系列単位の集計も併記する。
5. testの結果を見て方式を変更した場合、そのtestを新方式の最終未見評価として再利用しない。変更履歴を残し、別の封印試料を用意する。

同一試料に3配置あるため、「全写真に対する誤差」と「試料ごとの平均誤差」を分けて残す。系列を単位とした不確実性の評価には十分な系列数が必要。少数のtestだけから狭い信頼区間を表示しない。

## 暫定合格基準案

安定性の初期基準は、同一原本の縮小/JPEG/軽い回転・明るさ変更で予測差の95百分位2g以内、最大5g以内。これは同一画像の変換に対する条件であり、重量の正確さや実距離への対応を保証しない。

重量精度は独立試料でMAE10g以内を中間目標、5g以内を最終目標とする。最大絶対誤差20g以下、重量別MAE10g以下、数値出力率90%以上等も、対応条件と試料数を決めた上で事前固定する。これらは案であり、現在のモデルが合格したという意味ではない。

拒否率=拒否件数/全入力、10g超誤差率=10g超件数/数値出力件数、総失敗率=(拒否または10g超)/全入力を併記する。数値を出せた写真だけでMAEを小さく見せない。未知製品、範囲外、全長欠け、強い反射などの拒否も別途確認する。


合成台帳を使い、共有祖先・複数親・派生画像・不明な系譜・欠けたグラフ・分割不備を検査する。個人の画像・CSV・SQLite・既存モデルは変更しない。このテスト成功を、実試料の独立性やモデル精度の保証として報告しない。
