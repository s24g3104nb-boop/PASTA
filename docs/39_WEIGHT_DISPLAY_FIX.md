# 重量計算・表示の修正と50g写真の受領状況（2026-11-18）

## 確認した不具合と修正

写真受付、画像品質、色マスク、本数候補、製品取得、校正、表示判定、保存を追跡した。

- 初回の実写真で古いデモ製品が初期選択され、新規登録後にも古い製品を参照する場合があった。保存された製品IDを返し、選択を引き継ぐ。複数の実製品があり選択履歴がなければ選択を求める。
- 結果画面は製品のセッション内コピーを使い続けていた。未保存の結果ではDBの最新行を読み直す。校正変更時は保存操作を一度止め、新しい計算を確認してから保存する。保存済み結果は履歴に使用した校正値を保持する。
- 校正への移動で空の編集画面が開く場合があった。対象製品を選択し、デモの場合は実製品の新規登録へ案内する。製品編集の競合は更新前の行との比較で検出する。
- 明瞭な6本を置いた暗い背景でも、全画面平均輝度11.11だけを理由に処理を打ち切っていた。色候補周辺の明るさ・輪郭も確認し、検出処理へ進める。
- 画像端の孤立した1画素でも重量を隠していた。検出の最小面積と長さを踏まえて端の候補を確認し、長い麺の欠けは引き続き拒否する。
- 3×3 closingで近接した複数の麺が1領域になる場合を検出証跡に追加した。検出数を推測で増やさず、再撮影を案内する。
- 束の断面には従来マスクに基づく確認がなく、一部の円だけで通常の重量を表示できた。円が説明する色領域の割合、未検出領域の厚さ、円内部の色、見切れを検査する。

判定は経験的な安全確認である。断面の90%被覆等は精度保証を意味しない。重なった麺の総本数や隠れた端は確認できず、実写での独立評価が必要。

## 利用者が確認できる情報

結果画面の「写真と重量の診断」に、読み込み、選択製品、登録した1本重量、自動本数候補、色領域の画素数、重量計算の可否と理由を表示する。「検出位置とマスクを見る」で重ね合わせを確認できる。本数の手入力は開発設定内で空欄から明示入力し、結果名と保存方式で区別する。

重量が表示される条件は、正の実製品校正があり、写真の品質と配置が対応範囲にあり、本数が正、接触・欠け等の問題を検出しなかった場合。検査を通過しても実物精度は未確認。密集・交差・隠れた麺、斜めの端面や背景混入では重量を表示できない場合がある。

DBのスキーマ変更はない。デモ製品を実製品へ名前変更して仮値を持ち越す更新を拒否する。従来の実測記録、栄養、日記、保存の二重送信防止を維持する。方式Bの学習・モデル切替は実施していない。

## 新規50g写真6枚

READMEとmanifestを受領した。manifestの記載はIMG_7589〜7594、各50g、前2枚は接触・交差のある広げ方、次2枚は縦の密集束、後2枚は横の密集束である。会話上の画像でその外観を確認した。

**この実行環境へダウンロードできた添付はREADMEとmanifestであり、6枚のJPEGは解析用ファイルとして存在しない。** 原本SHA照合、画素数の実測、マスク生成、本数・校正後重量の数値比較は6枚とも保留。会話上の表示から数値結果を補完しない。manifestのSHAは期待値として保持し、一致を確認した実測ハッシュとは扱わない。

実製品名・麺寸法・秤分解能・6枚間の物理試料の共有関係は未確認。過去の0.68g/本と同製品であることも未確認であり、今回の写真の校正値として自動採用しない。訓練・独立評価への割当は行わない。50gのラベルは診断結果の対照にだけ使用する。

6枚の原本ZIPを受領後は次のコマンドで検品と診断を実行できる。

```bash
python tools/diagnose_photo_manifest.py --manifest PRIVATE/manifest.json --images PRIVATE/photos --output PRIVATE/new-diagnosis
```

製品一致が確認された1本重量が提供された場合だけ、`--calibration`にその値を指定する。暫定換算値と表示を許可した値を別フィールドに記録する。原本欠落・SHA不一致は未測定のまま残す。写真・結果JSON・画像付きHTMLはローカル非公開の出力先へ保存する。

## 既存実写による前後比較

以前受領した18原本をSHA照合し、同じ既定パラメータで比較した。50本34gの3視点で本数候補は8・7・10のまま。真上の8候補は以前から接触で拒否され、端面7・10候補から旧版が表示し得た4.76g・6.80gは修正後に拒否された。これにより大幅な過少計算の表示経路を閉じたが、50本を認識できた成果ではない。

以前の20〜100g・15枚も全て拒否された。端面モードへの誤った切替を試した15枚も修正後は全て拒否した。校正写真と同製品か不明な15枚の重量は計算しない。

closing無し、HSV+Lab、watershed、小円探索も比較したが、50本試料の視点ごとに結果が不安定である。小円探索は2端面で41・15候補となり、候補と実際の麺の対応も未検品である。実写の総本数回復を確認できる候補は採用していない。

今後は原本6枚を照合して同条件の診断を行い、製品の校正との一致、撮影距離・向き、見える端と隠れた層、正解マスクを確認する。複数重量と別々の物理試料がなければ重量回帰の汎化性能は評価できない。独立MAE・RMSEは未算出。
