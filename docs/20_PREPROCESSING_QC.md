元写真と受領プレビューを上書きせず、生成物はGit対象外の `data/Pasta_Lens_42_Photos/dataset/preview_qc_v2/` に保存する。重量ラベルは候補名から確定せず、今回も42件すべて未確認、承認0件、学習0件。

## ROI変換

`preprocessing.transform_roi` は参照画像寸法、対象寸法、EXIFの向き、座標が回転前か正規化後かを明示的に受け取る。矩形の4隅を変換し、EXIF正規化後に縮小倍率を掛ける。左上は切り下げ、右下は切り上げて矩形の範囲を保つ。正規化済みROIを再度回転しない。縦横比・座標が不正なときはエラーにし、黙って切り詰めない。

受領した7件の範囲外ROIには3264px級の値があり、対象プレビューは最大辺1536pxだった。元の基準寸法そのものは資料にないため、同じ縦横比・最大辺3264pxを仮定した変換を候補として適用し、推定であることをJSONと画面に記録した。これは原本寸法が確認できたという意味ではない。元寸法が分かれば `dataset/metadata/roi_reference_sizes.json` の該当項目を確認済みの値へ修正し、再生成する。

```bash
# リポジトリのルートで実行。画像を生成し直すが、ラベル・承認状態・学習は変更しない。
.venv/bin/python -m pasta_weight_app_v2.prepare_photo_qc pasta_weight_app_v2/data/Pasta_Lens_42_Photos --infer-reference-max-side 3264
```

`--infer-reference-max-side` を指定せず参照情報がない場合、範囲外ROIの推測変換はしない。各画像の変換前後座標・根拠・入力画素ハッシュ・候補マスクハッシュはローカルのmanifest.jsonに保存する。今回の42件は全件で候補作成でき、空マスクなし。自動承認はしない。

## 背景除去と形状

従来のHSV候補に加え、確かな色の領域と離れた長い領域を支持点にした候補を追加した。薄い色は強い色の近傍だけで採用し、背景の薄い色全体へ広げない。支持領域の凸包を拡張する場合も、最終的な前景を膨張・穴埋めする処理には使わない。暗い背景への合成は前景の元RGB画素をコピーし、PNGで保存する。生成AIによる描き直し、麺の平滑化、長さ・太さの拡大縮小はしない。

ただし、背景と麺が同じ色のとき、隠れた麺や細い先端があるとき、候補マスクが誤ることはある。画素を保持することと、全ての麺を正しく残すことは別である。自動領域数を本数の真値とは扱わない。実写候補には小物の混入や欠けが残り得るため未承認とし、従来候補から消えた画素も `lost_candidates/` の強調表示で検品する。

## 画面の確認と承認

「AI学習管理」→「受領パッケージ・重量確認・画像検品」で、加工前・加工後・二値マスクを並べる。オーバーレイ、ROI変換根拠、除外領域の残存画素を確認し、ROI・支持ポリゴン・手動追加／消去ポリゴンまたは修正済み二値PNGを使って修正できる。

候補を変更したら形状・漏洩チェックをリセットする。表示中候補のハッシュと保存済み承認マスクが一致しなければ学習候補に送れない。検品者、元画像／プレビューの種類、受領ハッシュ、寸法、座標情報、除外領域と承認内容を保存する。プレビュー版を検品する場合は、原本とは異なる版だと明示確認する。重量未確認でも検品はできるが、重量・同一計量・撮影セッション・製品・状態が未確認のまま学習には送らない。

## 秤と背景への依存を調べる

1. 秤表示・重量ラベル・小物は除外矩形や消去ポリゴンでマスクから除く。手動追加の後に除外領域を適用し、数字が戻らないようにする。指定領域の前景画素が0であることを検査する。領域未指定を「漏洩なし」とはみなさない。OCRで数字が見えないだけでも安全とは判断しない。
2. `controls/` に、同じ前景を暗色／灰色背景へ置いた画像と、前景を隠した背景のみの対照画像を出力する。対照画像も私有データであり、同じ元画像・計量・撮影セッションに属する。独立した学習サンプルとして分割しない。
3. 重量が確定し独立した評価群が揃ってから、同一ホールドアウトで背景色変更による予測の変化、背景のみで重量を当てられてしまうか、別背景・別日でのMAE/RMSE/MAPEと失敗率を調べる。背景のみの対照は学習しない。今は正解値・独立性が未確認なので、これらの性能指標は算出しない。

42枚は仮に4群であり、42独立試料ではない。群間で同じ麺・撮影セッションを共有している可能性も確認する。現行方式はモード×製品別に独立したtrain3群以上と別のval/testを必要とするため、全件ラベルが確定しても不足し得る。追加撮影は別の計量・別日・背景・角度で行い、35g/75g等の中間重量も未使用評価用として確保する。
