# 04 OpenCV・AI学習・評価計画

## 課題を明確にする
**画像1枚から絶対重量を一意に知ることは一般に不可能**。束の裏側で隠れた本数、広げた麺の重なり、製品の太さ・長さ・材質、撮影距離に依存する。「マーカーなし」は可能な条件を制限する必要がある。

ユーザーの必須条件は「撮影時は乾麺だけ、束/広げの両方」。撮影手順や製品校正を工夫し、精度・失敗率を実測値で示す。

## アプローチ候補（精度はまだ比較していない）
1. **ベースラインA：OpenCV・本数検出**（現行）
   - 広げ：HSV抽出 → 連結成分 → 細長さを判定。
   - 束：端面のHough円検出。
   - 検出本数 × 1本あたりの重量（実測校正）。
2. **ベースラインB：手動本数入力**（上限的な性能検証）
   - 本数が真なら重量換算誤差はどの程度か。測定全体の誤差を「検出誤差」と「1本gの製品内ばらつき」に分ける。
3. **候補C：AIベースの物体検出・インスタンス分割**
   - 束の断面ひとつひとつにアノテーション。密集断面に強いモデルを比較。見えない本数の保証はできない。
   - 広げでは接触・交差がある場合に線の分割／インスタンス分割を検討。
4. **候補D：画像からgへ回帰**
   - 複数の重量・照明・距離・背景・製品について写真と真の重量を対応付ける。
   - 見えない情報は復元できないため、未知製品や撮影条件で性能低下し得る。

**まずはA＋Bの定量比較を行い、実写真での失敗が大きいモードにC/Dを導入**。最初から高価な深層学習前提にしない。

## 現在入手可能なデータに関する新情報
- ユーザーから **20g / 40g / 60g / 80g / 100g の乾麺写真が既にある**と報告された。データ本体はまだCodexに渡されていない。
- 1重量帯1枚ずつしかない場合、深層学習を実用精度で訓練するには不足する。実際の枚数、撮影距離・背景・照明・麺の状態（束/広げ）・製品・実測記録を確認する。
- 5段階を単純分類すると20g刻み等の値にしか対応できない。20g刻みでない値も予測したいなら回帰・本数検出や追加重量帯の学習が必要。
- 同じ乾麺20gを同じ形で連写した画像を学習用と評価用に分散しない。重量ラベルだけでなく撮影バッチ/セッション単位で分割する。

## 必須の学習・評価フロー
1. `dataset_template.csv` に実測重量、製品、状態、撮影条件、画像を登録。
2. 画像のEXIF/重複/破損、計測値の範囲を検査。
3. **同一秤量バッチ (`batch_id`)・同じ撮影セッションの画像は同じ分割**にする。時期・製品でのホールドアウトも別途試す。
4. `train / val / test` を例えば70/15/15%で分ける（バッチ単位）。量が少ない間は分割割合は参考で、評価可能数を優先。
5. ベースライン推定器→モデル学習→閾値や前処理のチューニング（val）→最後にtestを一度評価。
6. 学習済みモデルは `model_version`, `trained_at`, `training_data_hash`, `class_names`、評価結果などのメタデータと共に保存。
7. 本番推定結果にはモデル/方式の種類、製品ID、検出数、推定重量、警告を保存。

## 指標
- `MAE = mean(|pred_g - actual_g|)` 単位g
- `RMSE = sqrt(mean((pred_g - actual_g)^2))` 単位g
- `MAPE = mean(|pred_g - actual_g|/actual_g)*100%` （actual_g>0のみ）
- 中央値絶対誤差、偏り（平均符号付き誤差）、大外れ率。
- 「推定できた枚数 / 全枚数」も報告。**失敗写真を除外して精度を良く見せない**。
- モード別・製品別・量別・照明別・背景別に分解。
- 本数アノテーションがある場合、本数誤差と欠落／二重検出率を測る。

## MVP学習用ツール仕様
- `scripts/import_dataset.py`: CSVチェック・画像検証。
- `scripts/split_dataset.py`: バッチ単位の再現可能分割（seed固定）。
- `scripts/evaluate.py`: 学習未実施でも既存OpenCV推定器を実写真データで評価できる。
- `scripts/train.py`: AIモデルを導入した場合に、明示的なオプションで訓練する。**現時点で学習済みモデルを偽装しない**。
- `scripts/predict.py`: 画像1枚→構造化された結果とエラー／警告。
- `tests/`: 合成画像テストと異常入力テスト。ただし合成のみのスコアは実世界の精度としては使わない。

## 不確実性と入力ガイド
- 束の先端がカメラに向いていない、端面が潰れている、複数束が交差、広げた麺が重なりすぎ、ぼけ・露出不足では **再撮影指示**。
- 実測データに基づく信頼区間・誤差予測がない限り「信頼度90%」「±10g」などを作らない。
- 長さ固定を仮定し、折れた麺／不明製品は対応外として警告。
