## 実装

- ui/design.cssへライト・ダークの配色を集約。Pythonはテーマ名のみ選択する。背景・カード・文字・アクセント・枠・余白・角丸・フォーカスを共通変数で管理。
- 入力欄16px、ボタン48px以上、選択欄44px以上、キーボードフォーカス、無効状態、写真の最大表示高、栄養カードの小画面文字サイズを調整。日本語フォントと長い文字列の折り返しを整えた。
- 下部ナビをborder-box化し、スマホ幅の余白・セーフエリアを確保。OSのモーション軽減設定を維持。
- ホームに「撮影済みの写真から選ぶ」を追加。カメラが使えなくても写真選択へ直接進める。
- 設定と研究登録で同じA4ガイドを使用。100%印刷、100mm確認、四隅・全長・再撮影条件を示し、PDFダウンロードを用意。
- 研究画面に試料IDの説明と保存前の照合案内を追加。既存の品質判定・未承認保存・試料の関係・DB処理は維持。
- 日記の削除確認を選択した後、再描画で確認欄が閉じにくいように状態を反映。

## テーマとCSSの分担

ルートの.streamlit/config.tomlはStreamlit標準テーマの初期色・フォントを設定する。アプリ内「端末に合わせる／ライト／ダーク」と部品の配色・形状は共通CSSが担当。ui_shell.pyはアプリ所有クラスpl-theme-*を付けるだけとした。サーバーは変更後に再起動する。ブラウザのStreamlit標準テーマメニューはアプリの表示設定とは別である。

生成されるst-emotion-cache等のクラスは使用しない。自前のst-key-*を優先し、標準部品には限定したdata-testidを使用。既存のカレンダー7列やナビのセレクタは互換性のため維持しており、Streamlit更新時は画面テストが必要。すべての内部HTML依存を解消したという意味ではない。
