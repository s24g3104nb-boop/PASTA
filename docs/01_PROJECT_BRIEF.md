# 01 プロジェクト概要・背景

## 対象
名称：Pasta Lens（仮）

ユーザーのアイデアは「乾燥スパゲッティを秤に載せなくても、スマホで写真を撮るだけでおおよその重量を把握する」。

**ユーザーが明示した制約**：
- 乾麺を**束のまま**でも**広げた状態**でも測定したい。
- 写真に定規・硬貨・基準マーカーは置きたくない。
- 開発言語はPython。画像処理にはOpenCV、必要に応じてAIを使う。
- スマホから撮影・結果確認をしたい。PCがローカルサーバーでも試作はよいが、将来はPCなしで使える公開形態も検討。
- 最初は乾麺の重量＋カロリー、パスタデータ登録・更新、履歴を実装したい。
- 将来は完成したパスタ料理（調味料・具材を含む）のカロリーと栄養推定に拡張したい。
- 電子はかり（キッチンスケール）はユーザーが持っている。実測データを集められるが、**現時点では実物写真は未収集**。

## 工学的な捉え方
1. `画像 -> 乾麺の本数（または画像から重量を直接回帰） -> g`。
2. `g × 製品ごとの乾麺100gあたり栄養値 / 100 -> kcal・P/F/C`。
3. `撮影画像 + 条件 + 推定g + 実測g -> SQLite/CSV -> 評価と再学習`。

初期試作の重量推定は、**同じ銘柄・太さ・長さの麺**について「本数 × 1本の実測平均重量」で求めている。これ以外のパスタ種類や折れた麺、交差・束の隠れた本数では誤差が大きくなる。AI導入が必須という決定ではなく、実測検証で適した方法を選ぶ。

## 研究としての価値
- 撮影状態別（束／広げ）の難易度と精度の比較。
- 古典的な画像処理と機械学習モデルの比較。
- 同一製品／製品横断／条件外の撮影で汎化性能を測る。
- 過剰な精度主張を避け、再撮影条件と推定不能判定まで評価する。
