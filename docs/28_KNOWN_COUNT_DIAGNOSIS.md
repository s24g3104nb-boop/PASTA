# 実測本数のある写真の独立診断

`experiments/diagnose_calibration.py` は、50本・合計34gと利用者が確認した同一試料の3撮影状態を調べるオフライン専用コードです。本番推定・SQLite・UI・校正台帳を変更しません。製品情報が不明でも今回の試料についてのみ、候補数×（実測合計÷実測本数）の算術比較ができます。これは他製品へ適用できる校正や独立した重量推定評価ではありません。

原本と付属CSVは私用の `data/` に置きます。実行前に既存全ファイルのSHA-256台帳を保存し、既存画像との完全一致を照合してください。近似重複と同じ物理試料の撮り直しはSHAだけでは分かりません。以前の試料との関係が不明なら独立扱いしません。

```sh
.venv/bin/python -m pasta_weight_app_v2.experiments.diagnose_calibration \
  --originals PRIVATE_RECEIPT/originals --output PRIVATE_RECEIPT/diagnostics
.venv/bin/python -m pytest -q pasta_weight_app_v2/tests
```

Windowsでは `.venv/bin/python` を `.venv\Scripts\python.exe` とし、コマンドを一行で実行できます。

入力は `labels.csv`、`photos/`、ファイル名・本数・実測合計・算出平均・撮影状態・試料ID・SHA-256の列を持つ受領形式です。対象は `overhead_bundle` / `low_angle_ends` / `closeup_ends` の3枚、単一試料。原本ハッシュ・ラベル整合・パス・重複名を確認してから新規出力を作ります。既存出力への上書きは禁止します。

最長辺1400pxの既存入力処理、画面既定のOpenCV検出パラメータを使います。HSV基準とHSV＋Labについて、100%・75%・50%の18条件を比較します。基準マスクと候補数が既存検出器と一致することを実行時にも照合します。縮小は撮影距離を制御した実験とは異なります。

成果物は、候補座標と採否、候補数と正解本数との差、検証用重量換算、符号付き・絶対重量誤差、面積等の特徴量、原寸マスク・検出位置・比較パネル、CSV、HTML、ソースと原本ハッシュです。緑は採用候補、橙は条件で除外した候補、紫は抽出輪郭です。緑が真陽性であることを保証しません。真上の矩形の橙は面積条件を満たすが形状条件で除外した領域、端面の橙は色条件で除外したHough円です。

本数との差は正解との純差で、見逃し数そのものではありません。同じ端面の重複検出と背景誤検出も候補に混ざり得ます。円の重なり数は重複の疑いを調べる目印に過ぎず、近接する別の麺の可能性もあります。確定するには可視端面の位置・対応関係を人手で注釈する必要があります。

製品名・直径・長さ・秤の分解能・旧系列との関係は不明のまま保持します。0.68g/本から秤の分解能や測定不確かさは逆算しません。画像や数値表は公開GitHubへ登録しません。
