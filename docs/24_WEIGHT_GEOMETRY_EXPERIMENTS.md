# 重量推定の原因調査・比較実験（2026-10-28）

## 結論と採用判断

実写真での精度改善はまだ証明できていません。新方式をオフライン実験モジュールとして実装し、実際の測定画面・有効モデル・UI・製品DBは切り替えていません。36gの実機事例そのものの写真・製品・方式・実測値／推定値の組は未確認です。

確定40gの手元写真1枚では旧OpenCVの連結領域数が4でした。旧画面で仮のデモ校正1g/本を使った場合、4gと表示され、絶対誤差36gを再現します。これは**危険な旧設定の反実仮想による再現**であり、利用者の事例と同一だと特定したものでも、有効な校正による精度測定でもありません。現在の画面ではデモ校正を使った実写真の重量表示を既に拒否しています。

## コード・実データの調査

- 広げた状態：HSV色抽出→3×3 closing→細長い連結領域数。接触した複数本が1領域になります。最小面積160px等は撮影距離・解像度で意味が変わります。
- 束の断面：Hough円の半径8〜27px、最小間隔32pxなどの固定値。小さい端面は検出範囲から外れ、隠れた端面は認識できません。
- 束の側面：見える投影面積だけでは奥行き・層数が不明。断面検出への流用を禁止する現行処理は維持。
- 既存回帰：RGB/HSVの平均・分散・色分布と4×4の領域特徴、計36次元。128×128への変形・縮小で細い麺の幾何形状が失われ、背景や画面内配置の影響を受けます。
- 製品：調査環境には仮の1g/本のデモ製品しかありません。実際の麺径・全長・一定本数の実測重量が必要です。
- モデル選択：ローカル学習済みモデル0件。管理処理はアーティファクトSHAと特徴量形式を確認します。画面は選択したモデルIDを測定記録へ保存し、前景専用モデルへの生画像入力を拒否します。利用者端末のモデル状態は未取得です。

|確定重量|旧方式の連結領域数の範囲|
|---|---:|
|20g|2〜6|
|40g|0〜6|

この数値は本数の正解でも重量推定値でもありません。写真には多くの麺が見える一方、処理は少数の塊を返しており、本数換算の前提が崩れています。

色のみの候補マスクは33/33枚で画像端に達し、19/33枚で色閾値変更に15%以上の変動がありました。背景や影の混入が疑われますが、麺の見切れと同一視はできません。細長い形状を残す診断用フィルタでは画像端接触が13/33枚へ減る一方、5枚は空マスクになりました。正解マスクとのIoUはなく、改善とは認定せず、この背景フィルタは自動採用していません。

33枚のQC承認・物理試料グループ確認は0。実写真の学習0枚、独立評価0枚です。実写真のMAE/RMSE/重量別誤差/失敗率は算出不可で、仮の校正値による数値を代用していません。

## 実装した候補

`geometry_candidate.py`：

- HSVとLabの色条件を併用。中性色の影・白い反射を除き、隣の麺を結合するclosingを行わない。
- Zhang–Suen骨格化と距離変換で総延長、麺幅、面積、端点、分岐、密度を取得。
- 面積÷（麺幅×期待全長）、総延長÷期待全長を計算。期待全長は見かけの麺幅×製品全長/直径から求め、画素倍率への依存を減らす。端点数との不一致時は拒否。
- 製品ID・直径mm・全長mm・10本以上の本数と総実測gによる校正を要求。
- 単層・垂直撮影の確認、幅のばらつき、見切れ、色マスク不安定性を棄却条件にする。しきい値は工学的な条件で、統計的な信頼確率ではない。
- 同じ平面に置いた実寸既知の四角形4点からのホモグラフィ補正。皿の寸法・カメラ姿勢を勝手に推測しない。重なって平面から浮いた麺には保証しない。
- 断面は距離変換の局所最大から半径と中心を抽出し、円面積と中心数を照合。正面・全端面可視を要求。
- 側面は幾何方式のg出力を拒否。学習回帰は独立データが揃ってから別モードとして検証する。

比較には既存36次元回帰、8次元幾何特徴の回帰、幾何推定と幾何回帰が一致する場合のみ平均するハイブリッドを実装。モデルは実験専用形式で、既存の本番モデルローダーでは受理されません。

## 再現手順

```sh
.venv/bin/python -m pasta_weight_app_v2.experiments.geometry_benchmark --output pasta_weight_app_v2/data/NEW_EXPERIMENT
.venv/bin/python -m pasta_weight_app_v2.experiments.endface_benchmark --output pasta_weight_app_v2/data/NEW_END_REPORT.json
.venv/bin/python -m pasta_weight_app_v2.experiments.diagnose_confirmed --photos PRIVATE_PHOTO_DIRECTORY --output pasta_weight_app_v2/data/NEW_DIAGNOSTICS.json
.venv/bin/python -m pytest -q pasta_weight_app_v2/tests
```

独立した実データが整った後は、同じ分割・校正・画像に対する6方式比較を実行できます：

```sh
.venv/bin/python -m pasta_weight_app_v2.experiments.compare_dataset --csv PRIVATE_LABELS.csv --calibrations PRIVATE_PRODUCTS.json --output pasta_weight_app_v2/data/NEW_REAL_EXPERIMENT
```

既存CSV必須列とsplitに加え、`weight_verified=YES`, `group_verified=YES`, `physical_sample_id`, `qc_status=APPROVED`, `leakage_checked=YES` が必要です。幾何推定には撮影確認として `single_layer`, `perpendicular`, `all_tips_visible` を必要に応じてYESにします。未確認の状態をYESで埋めてはいけません。校正JSONは製品IDをキーに、値は `product_id, diameter_mm, length_mm, weighed_strands, weighed_mass_g`。直径・長さはmm、質量はgです。

出力はデータハッシュ、受信画像ハッシュ、分割、試料ID、各行の予測・拒否理由、MAE/RMSE/MAPE/最大誤差、重量・状態・製品・照明・背景別集計、共通成功集合比較、係数・正規化・バージョンを保存。実験結果・写真は非公開のdata以下に置きます。既存モデルを上書き・自動採用しません。
