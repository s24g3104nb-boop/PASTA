# 02 機能要件／非機能要件（開発仕様案）

`P0`: 次の実装対象 / `P1`: 実データで必要 / `P2`: 将来拡張。未完項目も含む。

## 非機能要件
| ID | 分類 | 要件と評価方法 |
|---|---|---|
| N01 | 利便性 | スマホの画面幅で操作が成立。写真→推定結果まで迷わず進める。実機で手動検証 |
| N02 | 速度 | 画像送信後10秒以内の結果表示を**初期の目標値**にする。性能未測定なので実測して見直す |
| N03 | 正確性 | MAE/RMSE/MAPEと推定不能率を、撮影状態・製品・撮影条件別に評価。誤差目標は予備実験後に設定 |
| N04 | 安全性 | 未検証の重量・栄養値は推定値と明記。検出不能時は無理に確定値を返さない |
| N05 | プライバシー | 保存写真・履歴を無認証の外部アクセスから保護。画像とDBに実データがある場合は公開しない |
| N06 | 保守性 | 分析ロジックとUI分離、依存関係・起動手順を明示、テストを追加 |
| N07 | データ品質 | 実測・製品情報・撮影状態・採取日・同一秤量グループを保持し再現性を確保 |
| N08 | 可用性 | ローカルPC停止時に使えない旨を明示。将来常時稼働には別ホスティングを選択 |
| N09 | 対応環境 | Windows上のPython環境、PC Chrome、スマホSafari/Chrome。OS・バージョン別に検証 |

## 受入条件（段階的）
- **MVP 受入**：サンプル2モード、重量計算、栄養、製品登録、履歴、エラーハンドリングが動き、テストを通過する。
- **研究用評価ツール受入**：実写真データの取り込み・分割・評価結果が再現可能。学習モデル未訓練でも利用可能。
- **実物推定版受入**：同じブランドの未使用実画像でモード別評価を公開し、失敗ケースと適用条件が説明されている（精度数値はデータ後に決定）。
- **スマホ公開版受入**：認証・データ保存先の安全性・カメラ／アップロード・モバイル表示を実機で確認。
