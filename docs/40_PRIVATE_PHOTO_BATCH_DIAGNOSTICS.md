# 実写真バッチの検出・回帰比較と再現方法

画像受付、前景マスク、本数候補、校正、表示判定をローカルで再実行する実験用コードを追加した。写真・ラベル台帳・マスク・特徴量・学習結果は非公開の新しい出力ディレクトリーへ保存する。既存DBとモデル管理は使用しない。

## 実装

`experiments/photo_batch_diagnosis.py`は複数バッチの原本SHAを検査し、現行HSV、closing無し、既存のHSV+Lab、明るさ補正、既存の支持領域方式を同じ本数解析ルールで比較する。候補マスクの生成には正解ラベル、ファイル名、重量別フォルダー名を渡さない。

通常の`detect_spread`と実験用の`analyze_spread_mask`が本数解析の実装を共有する。通常のHSV入力を同じ関数へ渡したとき、本数・証跡・マスク・重ね合わせ画像の一致をテストする。新候補マスクは独立した比較用コードから利用する。

画像特徴には前景率、回転外接矩形の長短辺、密度、周囲長、連結成分、エッジ密度、方向性、内部質感を記録する。回帰は共通の長辺960px前処理と固定された特徴群を使用し、線形、Ridge、Random Forest、Gradient Boostingを比較する。既知重量の原本のみで訓練内適合を調べ、本数のみ既知の画像、縮小・回転派生画像は訓練へ追加しない。独立性未確認のバッチは一つの未解決系列として扱い、独立MAE/RMSEはnullを保存する。

`tools/diagnose_photo_manifest.py`はphotos/label形式とimages/weight_g_user_reported形式を明示的に読み分ける。曖昧な両形式の混在を拒否し、重量と本数の意味を保持する。

`tools/check_real_photo_flow.py`は一時DBへ製品を作り、実写真を本体の受付・解析・結果画面へ入力して、校正更新と検出結果の保持を確認する。人工の校正値は製品同期を試すためのfixtureで、提供写真の実製品の校正として扱わない。結果は非公開に出力する。

## 実行

研究依存ライブラリを入れたPythonで以下を実行する。ROOT_A/ROOT_Bはそれぞれmanifest.jsonとphotosを含むZIP展開先。OUTPUT_NEWは既存のデータと分けた未使用の非公開フォルダー。

```
python -m pasta_weight_app_v2.experiments.photo_batch_diagnosis --dataset ROOT_A --dataset ROOT_B --output OUTPUT_NEW
python tools/check_real_photo_flow.py --dataset ROOT_A --dataset ROOT_B --output PRIVATE_NEW_RESULT.json
python -m pytest -q pasta_weight_app_v2/tests pasta_weight_app_v2/experiments/research_tests tools/tests
```

レポートには写真別JSON/CSV、比較マスクと重ね合わせ、特徴変化グラフ、各探索モデルの訓練内誤差、同一画像変換への感度を出力する。元画像に戻って手動検品する。候補マスクの画素数の変化を抽出精度の向上や重量精度の改善と同一視しない。

## 今回の判断

両バッチ24原本の読込・SHA照合を完了した。現行本数方式は密集束を0〜少数候補と認識し、通常の重量出力には進めなかった。追加の重い10枚も全件停止で、校正値を正と仮定しても密集等の画像判定が残る。製品一致が未確認の0.68g/本は流用していない。

既知10本の2枚では、通常HSVに背景が混入した。以前から定義されていたHSV+Lab候補では両方10候補となった。重い密集束では総本数回復に至っておらず、追加の独立検証が必要。面積は撮影距離・配置・隠れた層の影響を受け、重さに対して一意にも単調にもならなかった。

新しい探索モデルは本番登録せず、研究用コードで比較を継続する。訓練誤差が小さくても同じ画像の変換で変動し、独立した試料の精度を確認できていない。検出成功、重量表示、未知試料精度の確認はそれぞれ別の検証結果として報告する。

実写真・個別特徴・モデル予測・画面プレビューを含む成果物は公開Gitの対象外。バックアップZIP、原本保護台帳、既存データ台帳で終了時にハッシュを再確認する。
