# 重量推定失敗時の復帰・実測記録（2026年11月11日）

ブランチui/polish-20261111。mainへのマージ・commit/pushは行っていない。UI改修前からの未コミット研究コードを保持し、方式B・マーカー・研究登録ロジックと既存モデルは変更していない。

## 原因と変更

capture_ui.pyは検出関数が返った直後に「解析が完了しました」と表示し、その後にweight_gateが実製品の未校正を拒否していた。検出処理完了と重量推定成功は別の状態であるにもかかわらず、校正警告だけで操作が終わっていた。

現在は「検出処理を終え、重量を計算できるか確認中」と「重量を推定した」を区別する。校正不足・検出ゼロ・写真品質不足・モデルなし・推定例外では、実測入力、撮り直し、校正設定への操作を表示する。校正画面から元の写真へ戻れる。未検証モデルを学習・本番採用する必要はない。

新規manual_weight_ui.pyで、写真付きの失敗後とホームの「写真なしで実測重量を記録する」の両方を扱う。0g以下は保存せず、保存失敗時も写真・入力値を保持する。実測100gと製品の100gあたりの表示値から乾麺分のカロリー・PFCを計算する。デモ製品・未登録の栄養情報（kcalが0等）は未計算とし、0kcalを正解として表示しない。材料・ソースを含めない。

実測記録はestimated_g=NULL、actual_g=実測値、estimator=manual_weight。画像なしではimage_filename=NULL。CG画像からの実測操作確認はsource_kind=synthetic、通常の実測はreal。推定値へ実測値を代入しない。未校正のg_per_strandも書き換えない。送信IDで再送を重複登録しない。

履歴表示・日記の選択表示・栄養スナップショットはNULL推定に対応。実測だけの記録をMAEへ混ぜない。実測履歴の重量を修正した場合は、保持した製品スナップショットから履歴の栄養を更新する。日記の保存済みスナップショットは変更しない。既存の料理使用中履歴の編集制限・二重計上防止を維持する。

## DB移行と復元

manual_measurement_storage.pyは手動記録の初回保存時だけ、推定重量と4栄養値のNOT NULL制約を外す。値・列・ID・インデックス・トリガー・AUTOINCREMENT連番を保持し、一つのトランザクションで置き換え、外部キー整合性を確認する。旧履歴の値は変更しない。未対応のスキーマで処理に失敗したらロールバックする。

変更前にSQLiteのバックアップAPIで `measurements.sqlite3.before-manual-weight-*.backup` を作成する。バックアップ失敗時は移行しない。写真は既存フォルダのまま保護する。DB保存完了後の通知例外でも、確定状態を確認して保存済み写真を削除しない。確定状態を確認できない場合は写真を保持する。

復元する場合はアプリを停止し、現在のデータフォルダ全体を別名で退避する。選択したバックアップDBを別フォルダのmeasurements.sqlite3としてコピーし、対応するphotos・meal_photos等もコピーする。PASTA_DATA_DIRを復元先へ向け、履歴・日記・写真・SHAを確認する。使用中DBやWALへバックアップを上書きしない。DBバックアップだけでは写真は復元されない。

## 検証結果

自動テスト459件成功。追加6件は、推定NULLと実測100g、バックアップ、外部キー・カスタムインデックス、旧履歴の不変、書込失敗、二重送信、画像なしUI→栄養350kcal→日記→履歴、コミット後例外での写真保護を含む。

Chromiumは専用DBと合成画像を使い、実際のcapture_ui.render_resultsを呼ぶ隔離した試験画面で確認した（iPhone実写ではない）。

iPhone Safari実機、Windows実機、カメラ権限、印刷物、重量推定の実写精度、破損した任意DBからの自動復旧は未検証。独立した試料で精度を確認するまでは新モデルを本番採用しない。

## Windows起動・利用

リポジトリのルートで `python -m pip install -r pasta_weight_app_v2/requirements.txt`、`python -m streamlit run pasta_weight_app_v2/app.py`。起動中なら停止して再起動する。実データで初回実測保存する前に、空き容量とバックアップ保存先を確認する。

写真解析後に推定できなければ、表示理由を確認し、そのまま「実際の重さを入力する」で電子はかりの値を入力→実測重量を履歴に保存→この乾麺で料理を記録する。写真なしではホームの専用ボタンから製品を選択する。校正値がなくても実測記録は可能。栄養が未登録なら未計算のまま記録できる。
