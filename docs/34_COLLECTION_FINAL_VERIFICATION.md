# 登録機能の仕上げと総合検証（2026年11月11日）

研究専用画面で写真・実測重量・製品・試料ID・セッション・再利用/追加関係を保存できる。登録前に暗さ、ぼけの参考指標、麺色領域の画像端接触、A4マーカー数、紙面基準の利用可否を表示し、同じ診断を原本から再計算して保存する。全体可視性は自動保証せず「確認が必要」または「撮り直し推奨」とする。隠れた麺の量は判断できない。原本は不変で、引き継いだ欠け警告を余白で消さないテストを追加した。

保存上限を20MBへ統一。関係を切り替えた際の非表示の親IDをクリアし、基準を切り替えた際に確認チェックをリセットする。保存完了後の受領通知だけ失敗した場合も、DBの確定状態を確認して写真を保護する。再送は既存IDを返し、重量等が矛盾する再送は監査記録へ残す。全データは未承認で、自動学習・自動分割はしない。

自動テスト452件成功。Streamlit画面テストで、入力不足のエラー、写真・重量の画面移動後保持、実測40g保存、未承認状態と診断保存を確認。マーカー検出は部分隠れ・異なるID・遠近・入力不正等の合成テストで検証した。実印刷倍率の正しさは写真だけでは保証しない。印刷100%と定規による100mm確認を必須とする。

Chromiumで研究画面表示と合成PNGプレビューまで確認し、PC/スマホ幅のスクリーンショットを非公開data/capture_development_nov10/browserへ保存した。ただし、一連の自動操作は選択欄・画面移動後の待機でタイムアウトしており、Chromiumで保存失敗から再試行まで完走したとは報告しない。保存処理はストレージテストと画面テストで確認済み。ダーク表示、iPhone、Windows、カメラ権限、印刷物・実写の寸法精度は未検証。
