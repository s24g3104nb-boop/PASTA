# 操作ログと第9回の単体テスト

## ログの仕様

重量推定、栄養計算、記録管理は、アプリを起動したPCの `PASTA_DATA_DIR/logs/pasta_lens.log` にUTF-8で記録します。`PASTA_DATA_DIR` を指定しない場合は `pasta_weight_app_v2/data` です。Windows配布版は起動バッチから指定された、配布フォルダー内のデータ保存先を使います。1行にUTC日時、INFOまたはERROR、機能名、固定の処理メッセージが入ります。1MiBで切り替え、直近3世代の旧ログを保持します。

| 機能 | INFOの例 | ERRORの例 | 仕様どおりの拒否・データなし |
|---|---|---|---|
| 重量推定 | 校正値と検出本数からの計算が完了 | OpenCVによる検出処理や校正情報の読み込みに失敗 | 未校正、麺の接触や重なり、画質不足により推定を見送る |
| 栄養計算 | 乾麺の栄養値または材料からの配分を計算 | 予期しない計算処理の例外 | 負数や無効な配分の入力拒否、栄養値未登録 |
| 記録管理 | 測定履歴や食事記録の保存・更新、食事記録の削除 | SQLiteやファイルの読み書きに失敗 | 入力不足、空の一覧、再送時の保存済み結果の返却 |

診断には固定のメッセージを使います。製品・料理・材料の名前、メモ、画像内容、画像ファイル名やパス、重量・栄養の入力値、記録ID、例外本文・スタックトレースは操作ログの項目から外しています。ログはSQLiteを使いません。ログ先が利用できない場合はサーバーの標準エラーに固定メッセージを出します。判定や保存の成否は、それぞれの処理の結果で決まります。

## 実行前に定義した単体テストケース

| ID | 対象 | テスト条件 | 期待結果 |
|---|---|---|---|
| W01 | 重量推定 | 黒背景の合成乾麺5本。校正は0.68g/本 | 3.4gを表示。重量計算のINFOが1件 |
| W02 | 重量推定 | 同じ合成画像で校正を未登録にする | 重量表示を見送り、実測入力を提示。ERRORなし |
| W03 | 重量推定 | 校正済みで麺が密集した形状の合成画像 | 重なりの案内と実測入力。重量表示とERRORなし |
| W04 | 重量推定 | 同じ解析結果画面でマスク表示を操作し再描画 | 計算結果を保持し、同じ重量計算のINFOを繰り返さない |
| W05 | 重量推定 | 検出処理に予期しない例外を注入 | 実測入力を提示。検出失敗のERRORが1件。例外詳細の転記なし |
| W06 | 重量推定 | JPEG欄に壊れた画像を渡す | 読み込めない案内と選び直し。画像入力の拒否をERRORにしない |
| N01 | 栄養計算 | 乾麺50g。100g当たり350kcal・P12・F2・C70g | 175kcal・P6・F1・C35g。乾麺計算のINFOが1件 |
| N02 | 栄養計算 | 乾麺0gと負重量を順に計算 | 0gは全項目0、負重量は拒否。負重量によるERRORなし |
| N03 | 栄養計算 | 乾麺350kcalと追加材料40kcalを2人で等分 | 390kcal、1人分195kcal。材料による計算のINFOが1件 |
| N04 | 栄養計算 | 栄養情報のない製品で実測100gを入力 | 栄養は未計算で表示・保存。値の補完とERRORなし |
| N05 | 栄養計算 | 同じ材料と0.25の取り分けで繰り返し計算 | 両回とも同じ結果、入力を保持。各正常計算のINFO |
| N06 | 栄養計算 | 材料の集計処理に予期しない例外を注入 | 計算失敗。栄養計算のERRORが1件。例外詳細の転記なし |
| R01 | 記録管理 | 一時DBに写真なしの実測100gを保存し再読込 | 実測として1件保存。推定値と写真は空欄。保存のINFOが1件 |
| R02 | 記録管理 | 料理名が空の食事記録を保存 | 入力を拒否。新規保存・ERRORなし |
| R03 | 記録管理 | 記録がない一時DBで一覧取得 | 測定履歴・食事日記とも0件。ERRORなし |
| R04 | 記録管理 | 同じ保存識別子で、写真付き測定を2回送信 | 同じ保存済みIDを返し、測定と写真を各1件に保つ |
| R05 | 記録管理 | 食事記録を追加・編集・一覧から削除 | 編集値を再取得でき、削除後は一覧から消える。各処理のINFO |
| R06 | 記録管理 | 一時DBのINSERTを失敗させる | 旧行・旧写真を保持、新規行・新規写真を残さない。保存失敗のERROR |
| L01 | 共通 | 同じログ設定を繰り返し、3機能のイベントを発生させる | 1ファイルに1イベント1行。日時・レベル・機能・固定メッセージ |
| L02 | 共通 | ログ先の初期化または書き込みを失敗させる | 固定の案内のみ。栄養計算や記録の戻り値・保存は仕様どおり |

仕様の根拠は計測・栄養・記録の設計と実装です。合成画像、テスト専用の製品・DB、例外注入を使います。写真の精度は独立した実測試料で別途評価します。Windows・iPhoneの実機と、実機の空き容量不足はこの単体テストの対象外です。

```text
python -m pytest -q pasta_weight_app_v2/tests/test_operation_logs.py
python -m pytest -q pasta_weight_app_v2/tests pasta_weight_app_v2/experiments/research_tests tools/tests
```
