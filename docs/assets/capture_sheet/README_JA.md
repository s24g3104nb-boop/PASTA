# A4撮影補助シート（研究用試作品）

PDFをA4・実際のサイズ・100%で印刷してください。「用紙に合わせる」「縮小して印刷」など自動倍率を無効にします。印刷後、下部の確認線が定規で100mmであることを測ります。写真だけからプリンタの倍率誤りを確実に検出することはできません。

紙を平らな台へ固定し、四隅の4マーカーと麺の両端を余白付きで写してください。中央の点線内に収まらない長い麺や大きい束は、端を切って撮影しないでください。マーカーを覆わず、真上から、明るく反射の少ない場所でピントを合わせます。

部分隠れ・ID不一致・基準の欠け・強い遠近や小さすぎるマーカーでは再撮影になります。4個検出されても印刷寸法と同一平面を確認するまではmm基準として利用しません。厚い束の高さ・重なって隠れた量は紙面の補正では解消しません。

検証は合成画像によるものです。実印刷・iPhone・重量推定精度は未検証です。

アプリ：設定 → 開発・検証ツール → 独立試料・撮影データ登録。写真、はかりの表示重量、製品名、試料ID、撮影会IDを入力します。以前の麺を再利用・追加した場合は元試料を指定します。基準を選び、確認結果を見て保存します。全記録は学習利用未承認です。
