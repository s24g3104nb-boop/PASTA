# Pasta Lens をWindowsで起動する

Python 3.12の入ったWindowsで、GitHubの最新版mainまたは配布ZIPを利用できます。一般的な使い方は写真から乾麺を測定し、完成した料理を日記へ残すことです。推定できない場合も電子はかりの実測値で記録できます。実写の重量推定精度は検証中で、方式Bを標準モデルにはしていません。

## GitHubの最新版を使う

1. GitHubの `s24g3104nb-boop/PASTA` を開き、ブランチが **main** であることを確認します。
2. **Code → Download ZIP** で取得し、旧版とは別の書込み可能なフォルダへ「すべて展開」します。旧フォルダへ上書きしません。
3. 展開した最上位フォルダの **setup_windows.bat** をダブルクリックします。Python3.12を確認し、このフォルダ専用の`.venv`へ必要ライブラリを導入します。初回はインターネット接続が必要です。
4. **start_windows.bat** をダブルクリックします。起動を確認した後でブラウザが自動で開きます。開かない場合は `http://localhost:8501` を開きます。
5. 終了するときは黒い起動画面で **Ctrl+C**。再利用時はstart_windows.batだけで起動できます。

以前のPasta Lensが起動したままだと8501番を使うため、新版の起動は止まります。旧版を終了してから再実行してください。黒い画面は使用中に閉じないでください。

GitHubから取得したコードの保存先は `pasta_weight_app_v2/data` です。専用のWindows配布ZIPの保存先は `user_data` です。明示的に環境変数PASTA_DATA_DIR等を設定している場合は、その設定を優先します。初回は空の履歴から始まります。

## 旧版から記録を安全に移す

1. **旧版・新版ともCtrl+Cで停止**し、写真や記録の保存が終わったことを確認します。
2. 旧版の設定にある「写真とデータの保存先」を事前に確認します。通常のGitHub版は`pasta_weight_app_v2/data`、前回の配布版は`user_data`です。
3. そのフォルダ全体を、日付を付けた別フォルダへコピーして保管します。DBのみでなく、photos、meal_photos、研究登録、学習関連ファイル、残っているSQLiteのWAL/SHMファイルも含めます。バックアップをGitHubへ追加しません。
4. 新版が未起動で保存先フォルダがまだない状態で、旧データフォルダ全体を新版の保存先へ**コピー**します。移動や上書きマージはしません。既に新版で記録を作った場合は両方保管し、自動的に混ぜないでください。
5. 新版を起動し、履歴件数・数件の写真・食事日記を確認します。必要なDB移行はバックアップ後に行われます。
6. 問題があれば両方停止し、旧版と変更前のバックアップへ戻します。新形式のDBを古いアプリへそのまま渡さないでください。移行後の新しい記録は別途保管します。

この手順は元のデータを残してコピーします。アプリは旧版の写真・DBを探して自動移動・統合・削除しません。大切なデータを持つ唯一のフォルダへZIPを上書きしないでください。

Gitを使う場合も先に停止・バックアップし、`git status --short`で未コミット変更がないことを確認します。`git fetch origin` → `git switch main` → `git pull --ff-only origin main`の順に実行します。競合や未コミット変更がある場合は停止し、`reset --hard`や`clean`で解消しないでください。依存が変わったときはsetup_windows.batを再実行します。

## iPhoneで使う

PCとiPhoneを同じ信頼できる家庭内ネットワークへ接続し、通常起動を停止して **start_lan.bat** を実行します。確認後Yを押すとLAN接続が有効になります。

PCのコマンドプロンプトで `ipconfig` を実行し、使用中のWi-Fi/EthernetのIPv4アドレスを調べます。例えば`192.168.1.23`ならSafariで `http://192.168.1.23:8501` を開きます。Windowsの許可は信頼できるプライベートネットワークに限定してください。詳細は[スマホ接続手順](packaging/windows/SMARTPHONE_JA.md)を参照してください。

認証機能はありません。同じネットワークの人が記録を閲覧できるため、公衆Wi-Fi、ルーターのポート開放、インターネット公開、公開トンネルは利用しないでください。HTTPのLANではブラウザ内カメラが使えない場合があります。標準カメラで撮影し、JPEG/PNG画像を選択してください。

## 未検証とデータ保護

Windowsのcmd.exe、Windows用wheel、実際のiPhone Safari・カメラ・LAN・プリンタはこの開発環境では未検証です。LinuxとChromiumのテストを実機検証とは扱いません。研究データや未検証モデルは配布ZIPに含めません。学習データ登録だけでは学習承認されません。

エラーが出た場合はPython3.12・空き容量・ネット接続・ファイルの展開漏れを確認します。配布ZIPは起動時にハッシュを確認します。GitHubソース版は必要ファイルと依存を確認し、開発中のソースを配布版のハッシュで拘束しません。安全性や重量推定精度を保証する仕組みではありません。
