# 🍝 Pasta Lens — 写真から乾麺の重量を推定（試作版 v2）

Python / OpenCV / Streamlit / SQLite で動く **PCで起動し、スマホのブラウザでも使える** 試作アプリです。

追記：現在のセットアップ、乾麺学習CLI、料理の材料計算は [リポジトリのREADME](../README.md) を参照してください。以下は元アプリの操作説明です。料理画像分類器は未学習、実写での重量精度も未検証です。

## 今できること

- **写真がなくても** 2つのCGサンプル（広げた乾麺12本、断面16本）で動作確認
- 広げた麺：黄色く細長い独立した画像領域をOpenCVで数える
- 束の端面：Hough円検出で断面の丸い部分を数える（精度未検証）
- 本数 × 製品ごとの1本あたり実測重量 → 推定乾麺重量（g）
- 重量 × 商品の栄養情報 → カロリー・P/F/Cを計算
- パスタの商品データをSQLiteに登録・更新
- 測定画像・推定重量・実測重量・栄養情報をローカルに保存して、履歴・誤差を確認
- スマホで画像アップロード、条件が合えばブラウザのカメラで直接撮影

> **注意**：AIモデルはまだ学習させていません。最初は調整と評価がしやすいOpenCV方式です。束の撮影を含む実写真の精度は未検証。麺が接触・交差すると特に誤検出しやすいため、電子はかりによる検証を続けてください。

## 1. 準備（Windows）

1. [Python 3.11 または 3.12](https://www.python.org/downloads/) をインストール（インストール画面で **Add Python to PATH** にチェック）。
2. ZIPを解凍して `pasta_weight_app_v2` フォルダを開く。
3. フォルダのアドレス欄に `cmd` と入力し、Enterでコマンドプロンプトを開く。
4. 次を入力。

```bat
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

ブラウザが自動起動しない場合は、PCから `http://localhost:8501` を開いてください。終了はコマンドプロンプトで `Ctrl + C`。

**うまく起動しない場合**：Windowsで `py` が見つからなければ `python` に読み替えてください。

## 2. 写真なしで試す

最初は「📷 重量を推定」→「サンプル画像（今すぐ試す）」になっています。

- 「広げた状態」：CG画像の12本の麺を検出する
- 「束の断面」：CG画像の16個の断面の円を検出する
- デモ製品の **1本=1g、350kcal/100g はすべて仮データ** です。実際の麺や栄養値を示すものではありません。
- 実際の写真で試すときは「写真をアップロード」に切り替える
- 認識を間違えた場合は「本数を手動修正」で結果の調整が可能
- 「この測定結果を保存」で履歴に保存

## 3. スマホから使う

PCとスマホを同じWi-Fiに接続してから、以下で起動します。

```bat
py -m streamlit run app.py --server.address 0.0.0.0
```

PCのLAN IPアドレスはWindowsで `ipconfig` →「IPv4 アドレス」で確認し、スマホのブラウザで `http://そのIPアドレス:8501` を開きます。Windowsファイアウォールに遮られる場合は、**信頼できるプライベートネットワークのみ**で許可してください。

- **HTTPでのカメラ直接起動はスマホブラウザの安全制約により使えない場合があります。** その場合はスマホの標準カメラで撮影し「写真をアップロード」で選択してください。
- 安全なHTTPS環境で公開する場合は、データ閲覧を防ぐため認証とアクセス制限が必要です。この試作は個人・ローカル実験向けです。

## 4. 実物の乾麺に合わせて校正する

1. 同じ商品・同じ長さの乾麺を例えば50本数える。
2. キッチンスケールで50本の合計重量を測る。
3. **合計重量 ÷ 50** で1本あたりの重量（g）を求める。
4. 「📦 パスタデータ」から製品名と重量、パッケージ記載の100gあたり栄養値を登録。
5. 撮影と推定を行い、可能なら実測重量を入力して誤差を調べる。

マーカーや定規は写真に不要です。ただし、**製品の実測校正が不要になるわけではありません**。

## 5. ファイル構成

```text
pasta_weight_app_v2/
├── app.py                  スマホ対応Web画面
├── pasta_vision.py         OpenCVによる本数検出・栄養計算
├── storage.py              SQLite / 写真保存
├── generate_demo.py        検証用CG画像の生成
├── sample_images/          CG画像（写真ではない）
├── data/                   実行後の履歴DB・写真（各自のPC内）
├── tests/                  処理ロジックのテスト
├── requirements.txt        必要なライブラリ
└── README.md
```

## 今後の開発

- ユーザーの実物写真を使って検出精度を検証・改良する
- 束の端面の認識精度が不足する場合、断面を人手でラベル付けした画像を使い、物体検出AIを学習する
- 撮影条件が悪い場合は「推定できません」と返す判定を改良する
- 調理後のパスタ料理について、食材・調味料の入力を含むカロリー計算に拡張する

### ダブルクリックで起動したい場合

`start_windows.bat` をダブルクリックすると、必要なライブラリをインストールしてアプリを起動します。Windowsが実行確認を求める場合は内容を確認してから実行してください。初回はインターネット接続が必要です。
