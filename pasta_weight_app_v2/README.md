# Pasta Lens アプリ本体

最新版の操作・Windows起動・更新方法は [日本語説明書](../README_JA.md)、機能と構成は [README](../README.md) を参照してください。

Windowsではリポジトリ／配布フォルダーのルートにある `setup_windows.bat` → `start_windows.bat` を実行します。専用の仮想環境と保存先を利用します。

通常画面はホーム・記録・設定です。写真から乾麺を解析し、推定できない場合も電子はかりの実測値で保存できます。完成料理は写真なし・栄養未計算でも食事日記に残せます。

写真による重量推定の実物精度は未検証です。研究用の方式Bは通常の推定処理に採用していません。サンプル2枚はCGで、実際の食事・重量評価のデータではありません。

手動で開発起動する場合は `python -m streamlit run pasta_weight_app_v2/app.py`（ルートから実行）。直接起動の既定保存先はこのディレクトリの `data/`、Windows配布ZIPではルートの `user_data/`です。GitHubのソース版は既存の `data/`を継続します。既存保存先は自動移動しません。
