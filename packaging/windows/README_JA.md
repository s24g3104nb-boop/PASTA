# Pasta Lens Windows配布版 — 2026年11月12日

Python 3.12（64bit推奨）がインストールされたWindows向けのソース配布版です。同梱のRELEASE_INFO.jsonで元のコミットとブランチを確認できます。旧版とは別フォルダで起動してください。実写での重量推定精度は未確認です。

## はじめ方

1. ZIPをダウンロードします。
2. ZIPを右クリックして「すべて展開」。ZIPの中から直接batを起動しないでください。書込み可能な新しいフォルダへ展開してください。
3. `setup_windows.bat` をダブルクリックします。専用`.venv`へライブラリをインストールします。初回はインターネット接続が必要です。システムのPythonへpip installしません。
4. 完了後、`start_windows.bat` をダブルクリックします。
5. 起動確認後にブラウザが自動で開きます。開かなければ `http://localhost:8501` を開いてください。起動した黒い画面は閉じないでください。
6. 終了時は黒い画面でCtrl+C。再利用時は起動batのみ実行します。

Pythonが見つからない場合はPython 3.12をインストールし、新しい展開先でやり直してください。`py -3.12`、なければ`python`の順に3.12を探します。別バージョンの既存仮想環境は削除・上書きしません。

Windowsの保護機能で確認が出た場合は、入手元とZIPのSHA-256を確認してください。セキュリティ機能を無効にする必要はありません。

## 最新機能

- クリーム/オフホワイト/セージの共通CSS、アプリ設定のライト/ダーク/端末連動。
- ホーム、写真選択・撮影、重量表示、写真付き食事日記、カレンダー、検索・編集・削除。
- A4補助シートの説明とPDFダウンロード。印刷100%・確認線100mmを定規で確認する研究用試作品。
- 校正不足・未検出・ぼけ・モデル不在等の際の実測入力、再撮影、校正設定への導線。
- 写真付き/写真なしの実測重量記録。推定重量と実測重量を区別し、実測だけなら推定値はNULL。
- 製品栄養があれば実測gから乾麺分のカロリー/PFCを計算、なければ未計算。
- 保存済み重量から食事日記へ連携。写真だけから料理全体のカロリーを作りません。
- 開発・検証ツールに研究用写真登録、品質表示、試料関係、重複検査。登録のみでは学習承認されません。
- 既存の食品管理・料理栄養計算・学習管理も保持。学習済みモデルと実写データは同梱していません。

## 最初に100gで試す

ホームの「写真を選ぶ・はかりの数値を記録する」を開く→「写真なしで実測重量を記録する」→製品選択→電子はかりの実測値100gを入力→保存→「この乾麺で料理を記録する」→料理名・食べた日を入力→保存。

初期製品は仮のデモ製品だけです。設定→製品・校正で実製品とパッケージの乾麺100gあたり栄養を登録してください。1本重量が未校正でも実測記録はできます。デモ製品の栄養は実際の記録に使用せず、未計算にします。画像推定を使う場合は実製品の校正が別途必要です。

## 保存先・旧版との関係

起動batは、このフォルダの `user_data` を使用します（PASTA_DATA_DIR等を自分で設定している場合はその設定を優先します）。SQLite、photos、meal_photos、research_collection、DB移行前バックアップはここに保存されます。空の初回起動時に作成されます。配布ZIPには個人のDB・写真・研究データ・モデル・秘密情報はありません。

**旧アプリのフォルダへZIPを上書きしないでください。** 旧版のDBやPython環境を変更せず、最新版を別フォルダで試せます。旧データの自動コピー・自動統合はしません。

両方のアプリを停止し、旧データフォルダ全体（DB、WAL/SHMが残る場合はそれも、写真、関連フォルダ）を別の安全な場所へバックアップしてください。旧GitHub版は通常pasta_weight_app_v2/data、以前の配布版はuser_dataです。新版をまだ起動しておらずuser_dataが存在しない状態で、旧データフォルダ全体を新しいuser_dataへコピーします。移動や既存フォルダへの上書きマージはしません。新版ですでに記録を作った場合は両方を保存して、自動的に混ぜないでください。起動後、履歴件数・写真・日記を確認します。DBのみコピーすると写真が失われる場合があります。必要なDB移行の前には控えが作られますが、元の唯一のDBを直接使用しないでください。失敗時は両方停止し、旧コードと変更前バックアップへ戻します。新形式のDBを旧コードへ戻さず、新しく作った記録は別途保管します。

## iPhone接続

同梱の `SMARTPHONE_JA.md` を参照してください。通常の起動batではPC内限定です。LAN用batは認証なしでネットワークに開くため、信頼できる家庭内のプライベートネットワークだけで使います。

## エラー時

- ファイル不足/ハッシュ不一致：ZIPを新しいフォルダにすべて展開。個人のuser_dataは消さず別途保管してください。
- importエラー：setup_windows.batで再インストール。ネット接続・空き容量・Python3.12を確認。
- 8501番使用中：旧版Pasta Lensなどを終了してから起動。
- 保存失敗：入力を残したまま空き容量・保存先のアクセス権を確認し再試行。
- 推定できない：実測重量を入力して保存。モデルの学習や校正を必須操作にはしません。

## 検証と未検証

`VALIDATION_JA.md` と `RELEASE_INFO.json` を参照してください。主要5ライブラリは新規環境で確認した版をrequirements.txtで固定し、その他の依存はpipが解決します。開発機での実測依存版はTESTED_VERSIONS.txtに記載しますが、Windowsの検証済み固定ロックとは異なります。

Windowsのbat実行、Windowsホイールのインストール、実際のiPhone/Safari・LAN・Windows Defender Firewallはこの環境では未検証です。Linux上で展開・初回起動・合成画像操作・専用DBによる保存を確認します。自動テスト成功は実写推定精度の証明ではありません。

コードを変更した場合、起動前のハッシュ検査は意図的に止まります。開発する場合は通常の開発環境を別に用意してください。個人写真やuser_dataは公開GitHubへ追加しないでください。

今回の重量推定の制約と修正は docs/38_DENSE_WEIGHT_DIAGNOSIS.md を参照してください。密集写真の高精度モデルは未採用です。警告の配色とナビ重なり、校正済み製品の復帰案内を修正しました。
